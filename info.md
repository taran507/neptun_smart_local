# Neptun Smart Local

Неофициальная интеграция Home Assistant для локального подключения Neptun Smart по Modbus TCP. Поддерживаются классический Neptun Smart, Neptun Smart SE, Neptun Smart+ и Dilwis Smart.

Отображает состояние модуля, проводных линий и радиодатчиков, показания предварительно настроенных счётчиков воды. Краны доступны как водяные клапаны (`valve`); настройка счётчиков через интеграцию не поддерживается.

После установки через HACS перезапустите Home Assistant и добавьте Neptun Smart Local в разделе «Настройки» → «Устройства и службы». Потребуются IP-адрес модуля, порт Modbus TCP (по умолчанию `503`) и адрес Modbus (по умолчанию `240`; для Smart SE часто `1`).

Радиодатчики регистрируются через переключатель «Регистрация радиодатчиков» и появляются в Home Assistant после следующего опроса. Подробности и инструкция по ручной установке приведены в [README.md](README.md).
