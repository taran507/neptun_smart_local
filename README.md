# Neptun Smart Local

Неофициальная интеграция Home Assistant для локального управления системой защиты от протечек Neptun Smart через Modbus TCP. Поддерживаются классический Neptun Smart, Neptun Smart SE, Neptun Smart+ и Dilwis Smart.

Интеграция показывает состояние модуля, проводных линий и радиодатчиков, позволяет управлять кранами и настройками устройства. Краны зон отображаются как водяные клапаны (`valve`). Показания настроенных и включённых счётчиков доступны как датчики объёма воды; настройка самих счётчиков выполняется вне интеграции.

## Установка

### Через HACS

1. Добавьте репозиторий `https://github.com/sergeylysov/neptun_smart_local` в HACS как пользовательский репозиторий категории «Интеграция».
2. Установите Neptun Smart Local и перезапустите Home Assistant.
3. Откройте «Настройки» → «Устройства и службы» → «Добавить интеграцию» и найдите Neptun Smart Local.

### Вручную

1. Скопируйте каталог `custom_components/neptun_smart_local` из репозитория в каталог `custom_components` вашей установки Home Assistant.
2. Перезапустите Home Assistant и добавьте Neptun Smart Local через «Настройки» → «Устройства и службы».

## Настройка

Устройство должно быть доступно по сети. Укажите его IP-адрес, порт Modbus TCP (по умолчанию `503`) и адрес устройства Modbus (по умолчанию `240`, допустимый диапазон `1–247`). Для Smart SE адрес часто равен `1`. Если устройство не отвечает, проверьте эти параметры и убедитесь, что другое подключение Modbus не занимает модуль.

## Добавление радиодатчиков

Включите на устройстве переключатель «Регистрация радиодатчиков» в Home Assistant и переведите датчик в режим регистрации согласно его инструкции. После регистрации новые сущности появятся при следующем опросе без перезапуска интеграции. Затем выключите переключатель. Поддерживается до 50 радиодатчиков.

## Обновление с версии с кранами-переключателями

Старые сущности кранов `switch` удаляются из реестра, а краны появляются как `valve`. Обновите автоматизации и панели, которые используют прежние `switch.*`: новым клапанам соответствуют команды `valve.open_valve` и `valve.close_valve`.
